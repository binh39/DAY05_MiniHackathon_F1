# VLearn AI Lecture Video UI

Thư mục giao diện độc lập cho màn `Day05_2 · AI Lecture Video`.

- Mặc định là giao diện sáng thực sự: nền, header, sidebar và các thẻ đều trắng; riêng thumbnail video dùng xám xanh rất nhạt.
- Nút `Giao diện tối` ở header cho phép xem biến thể dark dùng cùng bố cục.
- Không phụ thuộc vào ảnh hay thư viện ngoài; mở `index.html` bằng trình duyệt là xem được.
